# Above & Beyond

Finished the MVP with time to spare? Each of these previews a skill a later
module leans on — pick one or two, don't feel obligated to do all of them.

- **Find a second non-obvious pattern**, from a different slice of the data
  than the one you already wrote up in Part 3 — try `recclass` or decade
  instead. More reps at telling a real pattern from a coincidence is
  exactly what **Module 6** (dashboards), **Module 11** (inferential
  statistics), and **Module 12** (predictive analytics) all assume you
  already have.

- **Profile `reclong`** yourself — the fourth numeric variable, not
  required for MVP. Same five-number-summary/histogram workflow as Part 1;
  `data-distributions-shape` comes back as a real, practical concern in
  **Module 11**.

- **Quantify your Part 3 finding both ways.** Compute it using the mean
  *and* the median, and show numerically how different the conclusion
  would look if you'd reported the "wrong" one. This turns the
  mean-vs-median reasoning from "explain" into "prove" — the same
  judgment call that matters in **Module 6** (choosing a KPI's summary
  statistic) and **Module 5** (Business Analytics/KPI Development, where
  `critical-thinking` about a metric before reporting it is a formally
  reused skill).

- **Verify one of your memo.md questions for real.** Pick the most
  checkable one and actually try to answer it — a real search, not a
  guess — then write up what you found and whether it changed your
  confidence in your Part 3 pattern. This is the same "verify before
  trusting" habit **Module 13** (agentic AI tooling) and **Module 14**
  (responsible AI) formally assess later, applied to your own claim
  instead of an AI's.

- **Preview of Module 4 — code given, you don't need to write this
  yourself.** `above_and_beyond/pandas_preview.py` is a real pandas chain
  (filter → group → aggregate in one line) applied to this same dataset —
  a taste of what full pandas fluency looks like once you're writing it
  yourself. Run it, then add a short section to `memo.md` comparing what
  it tells you to your own Part 3 finding.

None of these change what counts as "done" per `MVP.md` — they're
optional, and a complete MVP without any of these is still a full, passing
submission.
